Routine prompt for the full process). Each daily cycle:

1. Writes 2 new guides for the topics listed below, in the same shape as the
   existing entries in `guides-seed.ts`'s `GUIDES` array, and ships them
   (PR → CI green → auto-merge, pre-approved for this routine only).
2. Replaces this file's 2 topics with 2 new ones for the following cycle —
   genuinely useful, Malaysia-SME-focused, and checked against every slug
   already in `guides-seed.ts` so nothing gets duplicated.

   to the account owner, so there's always a one-day window to redirect a
   topic before it actually gets written.
